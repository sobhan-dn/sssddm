# Letter Rush

A colorful, touch-first 2D runner for practicing English words. Pick the missing letter from four choices, then roll it across hills, crates, and obstacles.

## Run locally

```bash
npm start
```

Then open `http://localhost:3000`.

## Controls

- **Go:** right-side button or Right Arrow
- **Brake:** left-side button or Left Arrow
- **Boost:** lightning button or Space
- Letter choices, pause, and sound controls are all touch-friendly.
