# Letter Rush

A colorful, touch-first 2D runner for practicing English words. Pick the missing letter from four choices, then roll it across hills, crates, and obstacles.

## Run locally

```bash
npm start
```

Then open `http://localhost:3000`.

## Test on an iPhone

1. Connect the iPhone and the computer to the **same Wi-Fi network**.
2. On the computer, run:

   ```bash
   npm run start:iphone
   ```

3. The terminal prints one or more lines beginning with `iPhone:`. Open that exact
   address in Safari on the iPhone—for example, `http://192.168.1.20:3000`.
4. If the page does not open, allow incoming connections for Node.js in the
   computer's firewall and make sure the Wi-Fi does not use client isolation.

For an app-like full-screen experience, open Safari's **Share** menu, choose
**Add to Home Screen**, and launch Letter Rush from the new Home Screen icon.

## Controls

- **Go:** right-side button or Right Arrow
- **Brake:** left-side button or Left Arrow
- **Boost:** lightning button or Space
- Letter choices, pause, and sound controls are all touch-friendly.
